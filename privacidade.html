Política de Privacidade

Painel Canal Dark · atualizada em 28 de outubro de 2026

1. Quais dados o app acessa

Só os dados dos canais do YouTube que o próprio dono autorizar, pelas permissões de leitura:

  • youtube.readonly: o nome, a identidade visual e os números públicos do canal e dos vídeos;
  • yt-analytics.readonly: as métricas do YouTube Analytics e da YouTube Reporting API (views, tempo assistido, retenção, inscritos, impressões e taxa de cliques).

O app não pede acesso a e-mail, contatos, arquivos nem a qualquer outro dado da conta Google.

2. Como os dados são usados

Só para mostrar as métricas dos canais no painel pessoal do dono, que roda no computador dele. O app não publica, não altera e não apaga nada no YouTube.

3. Onde os dados ficam

No computador do dono dos canais. Os dados não vão para nenhum servidor do app, não são vendidos e não são compartilhados com terceiros.

4. Uso limitado

O uso e a transferência das informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

5. Como revogar o acesso

A qualquer momento, em myaccount.google.com/permissions: escolha "Painel Canal Dark" e remova o acesso. Os dados já guardados no computador do dono podem ser apagados por ele.

English summary

The app only reads, with the owner's consent, YouTube data (youtube.readonly) and YouTube Analytics / Reporting data (yt-analytics.readonly) for the author's own channels, to show them on his personal dashboard on his own computer. Data is not sent to any app server, sold or shared. Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at myaccount.google.com/permissions.
